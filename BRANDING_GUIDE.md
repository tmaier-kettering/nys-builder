## PDF export requirements

- Use the branding guidelines above.
- Change the title from **Selected Policies** to **Policies from the National Youth Statement on Climate**.
- Remove the unique policy number.
- Number policies consecutively in the order shown in the PDF.
- Remove the **Policy** label and format policy text left-aligned across full width with the first word bolded.
- If grouped by scope, do not include scope or jurisdiction in each policy section.
- If grouped by topic, do not include topic in each policy section.
- Format remaining rows as a two-column table: bold label on the left, value on the right.
- Format tools as a bulleted, underlined hyperlink list that opens the tools page with the selected tool shown in the right-hand panel.
